# 📡 Analyseur Terrain

Application mobile PWA pour analyser des fichiers Excel de données terrain.

## Fonctionnalités
- Import Excel/CSV (.xlsx, .xls, .csv)
- KPIs automatiques (total, open, taux d'exécution)
- Graphiques interactifs
- Filtres par région / statut / tâche
- Alertes sites Open
- Fonctionne hors-ligne (PWA)

## Utilisation
1. Ouvrir https://souleydiop.github.io/analytics
2. Appuyer sur "CHOISIR UN FICHIER"
3. Sélectionner ton fichier Excel
4. Analyser !

## Installation sur mobile
- Chrome Android : Menu ⋮ → "Ajouter à l'écran d'accueil"
- Safari iOS : Partager → "Sur l'écran d'accueil"
